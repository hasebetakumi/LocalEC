# なぜ「近所で予約して取りに行く売り場」が空いているのか

類似サービス調査（similar_services.md）の補足。「流行っていてもおかしくない領域が、なぜ誰にも取られていないか」を過去の事例から整理した。
結論は「儲かる場所が空いている」のではなく、「アプリ会社のやり方では成立しない場所が空いている」。

## 過去の挑戦と結末

| サービス | 期間 | 何をしたか | 結末と理由 |
| --- | --- | --- | --- |
| Reduce GO | 2018〜2021年 | 飲食店の余剰を月額1,980円で受け取れるアプリ | 登録ユーザーに対して店舗が集まらず終了。出品が出た瞬間に取り合いになった。店にとって余りは本来ゼロが理想なので、余り前提の供給は細く不安定だった |
| マチマチ | 2016〜2022年 | ご近所SNS。月間200万人、約130自治体と連携 | 事業化困難で終了。人は集まっても地域情報だけでは収益にならない |
| YACYBER | 〜 | 近所の直売所を探すアプリ | iOS版は提供終了 |
| ジモティー | 継続中 | 地域限定の売ります・あげます掲示板 | 生の野菜は出品禁止、賞味期限1週間以内の食品も不可。個人間の生鮮取引はトラブルになるため、運営が最初から避けている |

## 空いている構造的な理由

1. **供給が細く、波が大きい**。「ネギ800本」は年に数回のイベントで、毎日定額の出品を前提にしたTABETE型の設計では日常の在庫が保てない。開いても何もない日が続くと生活者は開かなくなる。
2. **1地域あたりの売上が小さい**。単価数百円で半径数キロが商圏だと、手数料10〜20%を取っても月に数万円。VC資金で全国展開する会社には投資対象にならない。
3. **出品作業を農家に任せると続かない**。写真・数量・価格の登録と予約確認は農繁期にはできない。全国産直ECでも農家の負担が離脱理由になっている。
4. **信頼と受け渡しの問題**。誰が来るか分からない相手に自宅や畑で渡すのはトラブルの元で、農家は見知らぬ人への配布を控えている。ジモティーが生鮮を禁止したのも同じ理由。
5. **既存手段でそれなりに回っている**。直売所、道の駅、LINEの個別案内で「なんとかなっている」ので、切り替える強い動機が生まれにくい。

## アケボノ様の案件が例外的に成立する条件

| 一般に成立しない理由 | アケボノ様の場合 |
| --- | --- |
| 買い手集めに一番金がかかる | 職員・父兄・地域グループが数百人規模で先にいて、売り切った実績がある |
| 供給に波があり、何もない日ができる | 農産物の合間をカフェの弁当やコインランドリーのキャンペーンで埋められる |
| 農家が出品作業を続けられない | 運営が掲載を代行し、事業者は情報を渡すだけ |
| 受け渡しの信頼が担保できない | 店舗や園など顔の見える場所で受け渡す |
| アプリ会社の採算に乗らない | 中核事業者が主体。自分の商圏の売上増と地域とのつながりが目的なら、1地域数万円でも成立する |

## 提案書への反映案

- 「なぜ空いているか」を1枚入れる。左に「大手がやらない理由」、右に「アケボノ様なら成立する理由」を並べる。
- 横展開の条件を同じ理屈で書く。「買い手のネットワークを持つ中核事業者がいる地域にだけ広げる」と明言すれば、関東3か所→10か所の数字に根拠がつく。
- リスクに「供給が途切れる日」を挙げ、対策として「複数事業者でカレンダーを埋める」「週1回の定期便でリズムを作る」を入れる。Reduce GOの失敗を踏まえた設計に見える。
