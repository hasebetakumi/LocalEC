## 1. 結論

| 項目 | 金額 |
| --- | --- |
| フェーズ1の開発費（見積もり） | 1,800,000円（税別） |

## 2. 前提

| 項目 | 内容 |
| --- | --- |
| 作るもの | iOS・Android・Web の一般ユーザー向けアプリと、スタッフ向け管理画面（Web・アプリ内） |
| 主な機能 | 商品・お得の掲載と予約、イベント・求人の掲載と申し込み、お知らせ、通知、店頭受け取り（現地決済） |
| 体制 | MeiN 1名。生成AIを活用し、少人数で工数を抑えて開発します |
| 期間 | 2026年10月〜12月。12月に職員の皆様でテスト運用、2027年1月に本番開始 |
| 単価 | 120万円／人月（1人月＝20人日、1人日＝8時間） |
| 単価の根拠 | システム開発会社の単価相場は、中堅SIerで120万〜160万円／月、エンジニア個人で60万〜120万円／月とされています（[出典：xnetwork「SIerの単価相場とは？」](https://www.xnetwork.jp/contents/system-integrator-fee)）。設計・開発・公開・運用までを1名で担うため、その境目である120万円としています |

## 4. 費用に含まれるもの・含まれないもの

| 区分 | 内容 |
| --- | --- |
| 含まれる | 上記の工程すべて。要件定義書（フェーズ1）に記載した機能 |
| 含まれない | フェーズ2以降の機能、要件定義書にない機能の追加（別途お見積もり）、利用規約などの法的レビュー、ストア開発者アカウントの年会費・登録料 |

## 5. 公開後の費用と権利の取り決め

| 項目 | 内容 |
| --- | --- |
| 保守費 | 2027年1月の公開後の監視、不具合修正、軽微な改善、サーバー等の実費は **MeiN が負担**します。アケボノ様へのご請求はありません |
| サーバー等の実費の目安 | 月2,000円〜20,000円程度（開始時はほぼ下限）。MeiN 負担 |
| コードの権利 | プラットフォームのソースコード・設計・データ構造の著作権は MeiN に帰属し、アケボノ様には本サービスを運営するための利用権を許諾します。店舗情報・掲載内容・利用者データはアケボノ様のものです |
| 権利を MeiN が持つ理由 | フェーズ3で他地域へ横展開するためです。横展開先の収益もアケボノ様と分配します |
| フェーズ2以降 | 開発費はいただかず、プラットフォームの収益をアケボノ様と MeiN で 1:1 に分配します |
