# 見積もり根拠（フェーズ1）

- 対象：`要件定義_フェーズ1.md` に定めたフェーズ1の実装
- 作成：MeiN
- 状態：工数1.5人月（30人日）、単価120万円／人月、開発費180万円で確定（2026-09-27）。レベニューシェア1:1に合わせて開発費も折半し、アケボノ様への請求額は90万円
- 用途：アケボノ様から「フェーズ1は開発費を支払い、フェーズ2からレベニューシェア」の提案を受けたため、フェーズ1の開発費の根拠として使う

## 2. 見積もりの考え方

生成AIで縮むのはコードを書く時間で、それ以外は縮まない。工程を2つに分けて見積もる。

- **縮む工程**：設計、実装。AIに書かせ、人は検証に回る。従来の3分の1〜半分
- **縮まない工程**：アカウント取得、実機での確認、ストア審査の待ちと差し戻し、職員のテスト対応、打ち合わせ。人と外部サービスが相手なので従来どおり

認証と行レベルセキュリティは、AIの出力がそれらしくても穴が出やすいため、人が確認する時間を残す。

## 5. 契約条件（フェーズ1）

| 項目 | 内容 |
| --- | --- |
| 開発費 | 見積もり180万円を両者で折半し、アケボノ様に90万円を請求する。残り90万円は MeiN の投資分 |
| 保守費 | **MeiN が負担する**。2027年1月の公開後、監視・サーバー等の実費（「6. ランニング費用」）に加え、OS の年次更新・Expo と Supabase の更新への対応、監視・不具合修正も MeiN が行う（自社の人件費のため費用には計上しない）。アケボノ様には請求しない |
| 製品の権利 | 権利は分けて持つ。**アケボノ様**：本サービスを独占的に利用する権利、サービス名、店舗情報・掲載内容・利用者データ。**MeiN**：本サービス（ソースコード、設計、データ構造）とロゴの著作権。理由は保守・改善を MeiN 負担で続けるため。MeiN の約束：①契約が続く限り MeiN の都合で止めない ②提供をやめる場合はソースコード一式を引き渡す ③他の運営者には提供しない |
| 横展開の扱い | 横展開はアケボノ様が運営する本サービスに他地域の事業者を追加する形。運営母体はアケボノ様のままで、横展開先の収益もアケボノ様と分配する（提案書16枚目） |
| レベニューシェア | フェーズ2以降、プラットフォームの収益をアケボノ様と MeiN で **1:1** に分配する。開発費の折半はこの比率に合わせたもの。フェーズ2以降の不具合修正・軽微な改善は MeiN 負担 |
| 範囲外の追加 | 要件定義書にない機能の追加は別途見積もる |

## 7. 工数が変わる要因

| 要因 | 影響 |
| --- | --- |
| Expo・Supabaseの経験 | 初めてのExpoプロジェクトだと環境まわりで+2〜3人日 |
| イベント・求人の申し込みフォーム | プロフィール以外の入力項目（希望日など）が必要なら、掲載ごとの項目設定が加わり+1人日 |
| デザインの手戻り | アケボノ様の確認で大きく変わると+1〜2人日 |
| ストア審査 | 差し戻しが重なると公開が1〜2週間遅れる。工数より日程への影響が大きい |
| ストア名義 | Google Playの個人アカウントは12人以上・14日間のクローズドテストが公開条件。Appleの法人アカウントはD-U-N-S番号に数週間。工数ではなく日程に効くため、10月中にアカウント取得を始める |
| LINEログイン（フェーズ2以降） | Supabaseの標準対応外で独自連携が必要。入れる場合は+3人日と不確実性 |
| フェーズ2以降に回した機能 | 地図表示+1、QRコード受け取り+1.5、キーワード検索+0.5、集計画面+0.5、無断キャンセルの自動処理+0.5、通知の種類別設定+0.3、Appleでサインイン+0.5（いずれも人日） |
