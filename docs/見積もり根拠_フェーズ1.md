## 5. 工数が変わる要因

| 要因 | 影響 |
| --- | --- |
| LINEログイン | Supabaseの標準対応外のため、独自の連携処理が必要。工程3の中で最も不確実。難航すればフェーズ1はメール＋Appleのみに絞る選択肢もある |
| イベント・求人の申し込みフォーム | プロフィール以外の入力項目（希望日など）が必要なら、掲載ごとの項目設定が加わり+2人日 |
| デザインの手戻り | アケボノ様の確認で大きく変わると+2〜3人日 |
| ストア審査 | 差し戻しが重なると公開が1〜2週間遅れる。工数より日程への影響が大きい |
| Web版のプッシュ通知 | フェーズ1では対象外。後から入れる場合は+2人日 |
